# Persona: The Fractional Consultant

## Overview

| Attribute | Value |
|-----------|-------|
| **Role** | Fractional CTO, technical consultant, or agency lead running discovery for clients |
| **Technical Proficiency** | High — understands both business and technical domains, familiar with structured methodologies |
| **Usage Frequency** | Heavy — multiple discovery sessions per week across different client projects |
| **Primary Device** | Desktop-primary for facilitation; mobile for quick reviews between meetings |

## Primary Tasks

- Facilitate discovery sessions with clients (often via voice/video)
- Guide non-technical stakeholders through the CID process
- Review and refine AI-generated artifacts before client approval
- Manage multiple concurrent projects across different clients
- Produce professional handoff packages for development teams

## Information Needs

- Quick access to project status across all clients
- Consistent discovery framework that clients can follow
- Token/cost tracking for billing or budgeting
- Export capabilities for client deliverables

## Context

- Desktop-primary for facilitation; mobile for quick reviews between meetings
- Needs to maintain separation between client projects
- Values efficiency — the platform should accelerate, not slow down, existing workflow
- Often conducting back-to-back discovery sessions

## Pain Points

- Currently chains prompts manually; time-consuming and error-prone
- Client conversations happen on Zoom but insights don't flow into documentation automatically
- Repeats the same discovery questions across projects; wants consistency without rigidity
- Context-switching between multiple client projects

## Current Workarounds

- Copy-pasting prompt templates between conversations
- Manual transcription or note-taking during client calls
- Storing outputs in client-specific folders manually
- Tracking token usage in spreadsheets

## Success Definition

> "I ran a discovery call, the platform captured everything, and I had a client-ready document in half the time."
